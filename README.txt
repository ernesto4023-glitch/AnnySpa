ANNNY BEAUTY STUDIO - LANDING PAGE

Archivos incluidos:
- index.html: landing page responsive completa.
- styles.css: estilos premium wellness, desktop y mobile.
- script.js: menú mobile, calendario, horarios, carrusel y confirmación visual.
- preview.html: vista de presentación con desktop y mobile lado a lado.
- assets/: imágenes recortadas del mockup de referencia para conservar la apariencia visual.

Cómo abrir:
1. Descomprime la carpeta.
2. Abre index.html en tu navegador.
3. Para ver la composición PC + mobile, abre preview.html.

Para editar:
- Cambia colores en :root dentro de styles.css.
- Cambia textos, precios, WhatsApp, dirección y horarios en index.html.
- Para conectar Firebase/Firestore, agrega la lógica en el submit de appointmentForm dentro de script.js.
